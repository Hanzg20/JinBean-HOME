本文档详细对比了三个版本的数据库架构：

## 🆕 v3.1.0 新增的关键功能详解

### 1. 🛒 购物车系统 (2个表)

#### 1.1 shopping_carts 表
**功能价值**: 支持多商品购物车，提升用户体验
```sql
-- 核心特性
- 购物车过期管理 (默认7天)
- 总计信息缓存 (性能优化)
- 行业特定购物车 (支持不同行业差异化)
- 配送信息预设
- 状态管理 (active, converted, expired, abandoned)

-- 业务价值
✅ 提升转化率: 用户可以逐步添加商品
✅ 减少重复输入: 保存配送信息和偏好
✅ 支持营销: 购物车放弃挽回策略
✅ 数据分析: 用户购物行为分析
```

#### 1.2 cart_items 表
**功能价值**: 购物车商品管理
```sql
-- 核心特性
- 商品定制选项支持
- 价格快照保护 (防止价格变动影响)
- 特殊说明支持
- 数量和价格验证

-- 业务价值
✅ 个性化定制: 支持商品个性化选项
✅ 价格稳定: 快照机制保护用户权益
✅ 订单准确: 详细的商品信息记录
```

### 2. 🔔 通知系统 (1个表)

#### 2.1 notifications 表
**功能价值**: 统一的多渠道通知管理
```sql
-- 核心特性
- 多类型通知 (订单、消息、系统、支付、评价、促销)
- 多渠道推送 (App推送、邮件、短信)
- 优先级管理 (低、普通、高、紧急)
- 过期控制和已读状态
- 深度链接支持 (action_url)

-- 业务价值
✅ 用户活跃: 及时的通知提升用户参与度
✅ 营销转化: 促销通知提升销售
✅ 服务质量: 订单状态通知提升透明度
✅ 用户留存: 个性化通知提升用户粘性

-- 通知类型覆盖
order: 订单状态变更通知
message: 新消息提醒
system: 系统公告和维护通知
payment: 支付成功/失败通知
review: 评价提醒
promotion: 优惠活动推广
reminder: 各种提醒通知
```

### 3. 📁 文件存储系统 (1个表)

#### 3.1 file_uploads 表
**功能价值**: 统一的文件管理系统
```sql
-- 核心特性
- 多文件类型支持 (头像、文档、图片、视频、音频)
- 访问权限控制 (公开、私有、受限)
- 处理状态管理 (上传中、处理中、完成、失败)
- 关联对象管理 (服务、订单、评价、消息)
- 文件元数据存储

-- 业务价值
✅ 用户体验: 丰富的媒体内容支持
✅ 安全控制: 细粒度的访问权限
✅ 存储优化: 临时文件自动清理
✅ 无障碍支持: alt_text支持

-- 支持场景
avatar: 用户头像、服务商logo
document: 证书、合同、发票
image: 服务图片、评价图片
video: 服务演示视频
audio: 语音消息
```

## 📊 性能和扩展性提升

### 1. 查询性能优化
