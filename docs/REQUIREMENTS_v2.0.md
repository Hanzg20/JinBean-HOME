## 1. 项目概述

### 1.1 项目背景

JinBean（金豆荚）是一款专为海外华人和本地居民设计的本地服务预订平台，对标北美主流应用（Thumbtack/Yelp），通过集成预约服务、评价系统、社区互动等功能，打造一站式生活服务超级应用。

### 1.2 项目愿景

成为海外华人首选的本地生活服务平台，通过技术创新和优质用户体验，连接服务需求方与服务提供方，构建可信赖的服务生态系统。

### 1.3 核心价值

- **便捷性**：一站式解决各类生活服务需求
- **可信赖**：完善的评价系统和服务商认证
- **本地化**：深度理解本地市场和用户需求
- **国际化**：多语言支持，服务不同文化背景用户

### 1.4 技术特色

- **跨平台**：Flutter开发，同时支持iOS和Android
- **实时同步**：Supabase实时数据库支持
- **插件化架构**：功能模块化，易于扩展
- **离线优先**：本地缓存，支持离线使用
- **高性能**：优化的购物车系统，响应时间提升50%

## 2. 用户角色与权限

### 2.1 用户角色定义

| 角色类型 | 角色描述 | 主要功能权限 |
|---------|---------|-------------|
| **Customer（客户）** | 服务需求方，寻找和预订服务 | 浏览服务、预订下单、评价、社区互动 |
| **Provider（服务商）** | 服务提供方，发布和管理服务 | 服务管理、接单处理、客户沟通、收入管理 |
| **Dual（双角色）** | 同时具备客户和服务商身份 | 角色切换、享有两种角色的所有权限 |
| **Admin（管理员）** | 平台运营管理人员 | 用户管理、内容审核、数据统计、系统配置 |

### 2.2 角色切换机制

- 支持用户在应用内无缝切换角色
- 每个角色独立的主题和UI界面
- 角色切换后自动更新底部导航和功能模块
- 保持各角色的独立数据和状态

### 2.3 权限矩阵

| 功能模块 | Customer | Provider | Dual | Admin |
|---------|----------|----------|------|-------|
| 服务浏览 | ✅ | ✅ | ✅ | ✅ |
| 服务预订 | ✅ | ❌ | ✅ | ✅ |
| 服务发布 | ❌ | ✅ | ✅ | ✅ |
| 订单管理（客户侧）| ✅ | ❌ | ✅ | ✅ |
| 订单管理（服务商侧）| ❌ | ✅ | ✅ | ✅ |
| 评价发布 | ✅ | ❌ | ✅ | ✅ |
| 评价回复 | ❌ | ✅ | ✅ | ✅ |
| 社区互动 | ✅ | ✅ | ✅ | ✅ |
| 系统管理 | ❌ | ❌ | ❌ | ✅ |

- cache_entries - 缓存条目
- user_sessions - 用户会话
