# JinBean Platform - 人工测试指南

## 📋 测试准备

**测试环境**: iOS模拟器 / Android模拟器  
**应用状态**: ✅ 已启动并运行  
**用户账号**: 已登录 (customer+provider 角色)  
**测试时间**: 预计 2-3 小时完整测试

---

## 🎯 测试流程概览

### **测试阶段**
1. **冒烟测试** (15分钟) - 基本功能验证
2. **P0核心功能测试** (30分钟) - 订单、购物车、智能路由
3. **P1高优先级功能测试** (30分钟) - 首页导航、服务详情、地址管理
4. **P2中优先级功能测试** (45分钟) - 行业页面、用户档案、支付系统
5. **P3低优先级功能测试** (30分钟) - 搜索功能、性能监控
6. **集成测试** (30分钟) - 端到端业务流程

## 🎯 测试技巧和注意事项

### **测试技巧**
1. **分步骤测试**: 每个功能分解为小步骤，逐一验证
2. **记录问题**: 及时记录发现的问题，包括复现步骤
3. **多场景测试**: 尝试不同的使用场景和数据
4. **边界测试**: 测试极限情况和异常输入
5. **用户视角**: 从真实用户的角度思考和测试

### **注意事项**
1. **数据库错误**: 日志中的数据库错误是正常的，说明在使用真实API
2. **网络问题**: 如果遇到网络错误，检查网络连接
3. **权限问题**: 某些功能可能需要特定权限
4. **测试数据**: 使用测试数据，避免影响生产数据
5. **性能观察**: 注意应用的响应速度和资源使用

### **常见问题排查**
```
问题: 页面加载失败
排查: 检查网络连接，查看控制台日志

问题: 功能按钮无响应
排查: 检查是否有JavaScript错误，重启应用

问题: 数据不显示
排查: 检查API调用是否成功，验证数据格式

问题: 页面跳转异常
排查: 检查路由配置，验证导航逻辑
```
