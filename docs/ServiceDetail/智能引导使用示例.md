# 智能引导使用示例

## 🎯 **核心优势**

### **解决痛点**
- ✅ **空间节省**：引导看3次后自动隐藏，释放界面空间
- ✅ **用户友好**：新用户有指引，老用户界面简洁
- ✅ **轻量实现**：基于SharedPreferences，无需复杂配置

## 📱 **使用方式**

### **1. 简单智能提示**

在任何需要引导的地方直接使用：

```dart
import 'package:your_app/core/widgets/smart_guide_hint.dart';

// 在Widget中添加
Column(
  children: [
    // 智能引导提示（自动管理显示/隐藏）
    SmartGuideHint(
      hintId: 'unique_hint_id',
      content: '💡 这是一个重要提示，看3次后自动隐藏',
      icon: Icons.lightbulb,
      primaryColor: Colors.blue,
    ),
    
    // 其他内容
    YourMainContent(),
  ],
)
```

### **2. 预定义组件**

使用预设的常用引导：

```dart
// Overview Tab中的Menu引导
MenuGuideHint(),

// Tab布局切换引导  
TabLayoutGuideHint(),

// 购物车操作引导
CartGuideHint(),
```

### **3. 紧凑模式**

在空间有限的地方使用：

```dart
SmartGuideHint(
  hintId: 'compact_hint',
  content: '这是紧凑模式的提示',
  isCompact: true,
  maxShowCount: 2,
)
```

### **4. 按钮式引导**

当空间极其有限时，显示为按钮：

```dart
SmartGuideButton(
  guideId: 'button_guide',
  buttonText: '操作帮助',
  guideTitle: '如何操作',
  guideContent: '详细的操作说明...',
  icon: Icons.help_outline,
)
```

## 🔧 **参数配置**

### **SmartGuideHint 参数**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `hintId` | String | 必需 | 唯一标识符，用于记住状态 |
| `content` | String | 必需 | 提示内容 |
| `icon` | IconData? | null | 图标 |
| `primaryColor` | Color? | Colors.blue | 主题色 |
| `maxShowCount` | int | 3 | 最大显示次数 |
| `autoHideDelay` | int? | 5 | 自动隐藏延迟（秒） |
| `showCloseButton` | bool | true | 是否显示关闭按钮 |
| `isCompact` | bool | false | 是否紧凑模式 |

### **行为说明**

1. **首次显示**：立即显示，5秒后自动隐藏
2. **第2-3次**：继续显示，用户可手动关闭
3. **第4次开始**：不再显示，界面完全简洁
4. **手动关闭**：用户点击关闭按钮，永久不再显示

## ⚙️ **调试功能**

### **重置所有引导状态**

```dart
// 开发时重置所有引导状态
Future<void> resetAllGuides() async {
  final prefs = await SharedPreferences.getInstance();
  final keys = prefs.getKeys().where((key) => 
    key.startsWith('hint_') || key.startsWith('guide_'));
  for (final key in keys) {
    await prefs.remove(key);
  }
}
```

### **检查引导状态**

```dart
Future<void> checkGuideStatus(String hintId) async {
  final prefs = await SharedPreferences.getInstance();
  final count = prefs.getInt('hint_${hintId}_count') ?? 0;
  final dismissed = prefs.getBool('hint_${hintId}_dismissed') ?? false;
  print('引导 $hintId: 显示次数=$count, 是否关闭=$dismissed');
}
```
