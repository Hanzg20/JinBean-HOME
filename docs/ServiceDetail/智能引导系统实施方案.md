# 智能引导系统实施方案

## 🎯 **解决问题**

### **当前问题**
- **引导文本占空间**：Overview Tab中的"如需选择具体菜品，请前往Menu标签"等引导文案始终显示，占用宝贵的屏幕空间
- **用户体验不佳**：新老用户看到相同的引导信息，缺乏个性化
- **信息冗余**：熟悉操作的用户不需要重复看到引导提示

### **用户需求**
- **新用户**：需要清晰的操作引导
- **老用户**：希望界面简洁，快速操作
- **空间优化**：更多空间展示核心内容

## 🧠 **智能引导方案**

### **核心机制**
1. **显示次数控制**：每个引导最多显示3次
2. **用户手动关闭**：用户可以主动关闭某个引导
3. **本地持久化**：使用SharedPreferences记住用户选择
4. **自动隐藏**：5秒后自动淡出（可配置）
5. **分类管理**：不同类型的引导独立管理

### **引导类型设计**

#### **1. Overview → Menu 引导**
```dart
GuideType.overviewToMenu: GuideConfig(
  maxShowCount: 3,
  title: '💡 购买提示',
  content: '如需选择具体菜品并加入购物车，请前往"Menu"标签',
  icon: Icons.restaurant_menu,
  primaryColor: Colors.blue,
  autoHideDelay: 5, // 5秒自动隐藏
)
```

#### **2. Tab Bar布局引导**
```dart
GuideType.tabBarLayout: GuideConfig(
  maxShowCount: 2,
  title: '🎨 布局切换',

  icon: Icons.layers,

```

#### **3. 购物车操作引导**
```dart
GuideType.cartOperation: GuideConfig(
  maxShowCount: 2,
```

## 🛠 **技术实现**

### **1. UserGuideManager**
```dart
class UserGuideManager {
  // 检查是否应该显示引导
  Future<bool> shouldShowGuide(GuideType type);
  
  // 记录引导显示
  Future<void> recordGuideShown(GuideType type);
  
  // 用户手动关闭
  Future<void> dismissGuide(GuideType type);
  
  // 重置引导状态（开发调试用）
  Future<void> resetAllGuides();
}
```

### **2. SmartGuideWidget**
```dart
class SmartGuideWidget extends StatefulWidget {
  final GuideType guideType;
  final Widget child;
  final bool autoShow;
  
  // 自动检查并显示引导
  // 支持淡入淡出动画
  // 自动隐藏定时器
}
```

### **3. GuideBubble**
```dart
class GuideBubble extends StatelessWidget {
  final GuideType guideType;
  final bool isCompact;
  
  // 轻量级引导气泡
  // 适合在列表中使用
  // 支持紧凑模式
}
```

## 📊 **预期效果**

### **空间节省**
- **首次访问**：显示引导，用户快速上手
- **第2-3次访问**：仍显示引导，确保用户记住
- **第4次以后**：不再显示，界面完全为内容让路

### **用户体验提升**
- **新用户**：有清晰引导，不会迷茫
- **老用户**：界面简洁，操作效率高
- **个性化**：每个用户的引导状态独立

### **维护性**
- **集中管理**：所有引导配置在UserGuideManager中
- **易于扩展**：新增引导类型只需要添加配置
- **开发友好**：提供重置功能便于调试

## 🧪 **测试计划**

### **功能测试**
1. **显示次数**：验证引导确实在第3次后不再显示
2. **手动关闭**：验证用户关闭后不再显示
3. **持久化**：重启应用后状态保持
4. **自动隐藏**：5秒后自动消失

### **用户测试**
1. **新用户体验**：是否能快速理解操作流程
2. **老用户反馈**：引导消失后界面是否更加简洁
3. **空间利用**：引导消失后空间是否得到有效利用
