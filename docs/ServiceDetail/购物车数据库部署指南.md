# 🛒 购物车数据库部署指南

## 📋 概述
本指南将帮助您在Supabase中部署完整的购物车系统数据库，包括所有必要的表、索引、权限和安全策略。

## 🎯 部署内容

### 新增表
- `unified_carts` - 统一购物车表
- `cart_items` - 购物车项目表  
- `cart_operation_logs` - 购物车操作日志表
- `negotiation_records` - 议价记录表
- `orders` - 订单表（如果不存在）
- `order_items` - 订单项目表

### 修改现有表
- `services` 表添加：
  - `supports_cart` (boolean) - 是否支持购物车
  - `booking_type` (text) - 预订类型
- `service_details` 表添加：
  - `current_stock` (integer) - 当前库存
  - `max_stock` (integer) - 最大库存
  - `is_available` (boolean) - 是否可用

### 其他组件
- 15+ 性能优化索引
- 完整的RLS安全策略
- 自动更新时间戳触发器
- 购物车统计视图

## 🚀 快速部署

### 步骤1：登录Supabase控制台
1. 打开您的Supabase项目
2. 进入 **SQL编辑器**

### 步骤2：执行部署脚本
1. 新建SQL查询
2. 复制 `docs/ServiceDetail/sql_scripts/complete_cart_database_setup.sql` 的完整内容
3. 点击 **运行** 按钮

## 🛡️ 安全特性

### Row Level Security (RLS)
- ✅ 用户只能访问自己的购物车
- ✅ 用户只能查看自己的订单
- ✅ 操作日志自动记录

### 权限控制
- ✅ authenticated 用户可以进行CRUD操作
- ✅ 匿名用户无法访问购物车数据
- ✅ 跨表查询自动验证用户身份

## 📞 故障排除

### 常见问题

**Q: 部署时出现外键约束错误**
A: 脚本已经处理了这种情况，会跳过不存在的表的外键约束

**Q: RLS策略冲突**
A: 脚本会先删除现有策略再创建新的，避免冲突

**Q: 权限不足**
A: 确保您有数据库管理员权限，或联系项目管理员

### 日志检查
如果部署出现问题，请检查：
1. Supabase日志面板
2. SQL执行结果中的NOTICE和WARNING信息
3. Flutter应用中的购物车错误日志
