## 🔄 状态说明

### 任务状态
- 📝 **待办（To Do）**：未开始的任务
- 🚀 **进行中（In Progress）**：正在开发的任务
- 🧪 **测试中（Testing）**：开发完成，测试中
- ✅ **已完成（Done）**：测试通过，已合并代码
- ⛔ **阻塞（Blocked）**：被依赖或问题阻塞
- 🗑️ **取消（Cancelled）**：不再需要的任务

### 优先级说明
- 🔴 **P0**：阻塞发布，必须完成
- 🟡 **P1**：核心功能，尽量完成
- 🟢 **P2**：增强功能，有时间完成
- 🔵 **P3**：长期规划，本期不做

### 标签说明
- `feature`：新功能开发
- `bugfix`：Bug修复
- `optimization`：性能优化
- `refactor`：代码重构
- `test`：测试相关
- `docs`：文档相关
- `backend`：后端任务
- `frontend`：前端任务
- `urgent`：紧急任务
